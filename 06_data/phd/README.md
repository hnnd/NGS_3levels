## 为什么是这条主线

博士层选 **水稻（*Oryza sativa*）— 稻瘟病菌（*Pyricularia oryzae*）** 作主线，理由三条：

1. **专业对口**：植病、昆虫、农药、微生物四个专业的公共交集就是植物—病原互作；稻瘟病是水稻头号真菌病害。
2. **一条数据链贯穿多个专题**：p03 的侵染时序转录组同时是 p06 的转录组层；p04 的群体重测序为 p05 的群体遗传概念提供实物；p07 直接复用 p03/p04 的子集。学生不必每讲换一套数据从头适应。
3. **单倍体的便利**：稻瘟菌是单倍体真菌，p04 的变异检测不必处理杂合位点，11× 覆盖度就够——这让群体基因组第一次跑得起来。

契约 `cross_level_consistency: per_level` 已定：跨层不强求同源。本层与硕士层的水稻线相接，但不与本科层的细菌线强行统一。

## p01 AI 辅助工作流：不需要外部数据

讲义的实践是"在已知正确答案的数据上抓 AI 的错"，用 `01_make_spikein_counts.R` 现场生成带 spike-in 的计数矩阵（固定种子 `20260829`）。**刻意不用真实数据**：只有正确答案已知，才能判定 AI 输出是对是错。讲义实测的三个数字（AI 版报 97 个差异基因 vs 参考 22 个、spike-in 上调侧命中 0/20、log2FC 相关 −0.99）就是在这套自造数据上得到的，可复现。

## p02 单细胞与空间转录组

### 单细胞：`GSE222584`（主选）

**出处**：Single cell sequencing revealed cell heterogeneity in rice infected with RRSV and RGSV（水稻茎基部，10X）。

**为什么选它**：

- **是水稻 + 病原互作**——与本层主线一致，不是"借一套动物数据讲方法"
- **9 个样本 = 3 处理（Mock / RGSV / RRSV）× 3 时间点（7 / 14 / 21 dpi）**，够做伪重复（pseudobulk）差异表达
- **采样日期天然构成批次**：文件名里的 `0828` / `0904` / `0911` 就是三次采样，**与 dpi 完全共线**。这正是讲义 ⑥「PCA 先回答批次还是处理主导」要讨论的情形——**这个共线是真实的、无法用统计手段拆开的**，学生必须学会说出"这份数据回答不了时间效应与批次效应谁是谁"
- 已是 10X 三件套（`barcodes.tsv.gz` / `features.tsv.gz` / `matrix.mtx.gz`），`Seurat::Read10X()` 直接读，**不必跑 CellRanger、不必准备参考基因组**

**自查判据**（实测）：`GSM6926986_CK0828` 的 barcodes 共 **4,515** 个细胞条码，带 `-1` 后缀（10X 标准）。九个样本细胞数在数千量级；过滤后（`nFeature_RNA > 200`、线粒体比例阈值按讲义 ⑤）应保留大部分。若某样本过滤后只剩几百个细胞，回查过滤阈值是否照搬了动物数据的经验值——**植物没有线粒体比例这个通用指标，叶绿体基因才是**。

### 空间：10X 官方 Visium 演示数据（⚠ 非植物）

**如实说明差距**：**公开的植物 Visium 数据非常稀缺**。检索到的域内空间数据要么用非 Visium 平台（`GSE316219` 水稻—丛枝菌根真菌，Resolve Molecular Cartography），要么样本极少（`GSE284052` 番茄—根结线虫，3 个样本），都不适合作为"跑通 `Load10X_Spatial()` 标准流程"的练手对象。

**折中方案**：用 10X 官方的 `V1_Mouse_Brain_Sagittal_Anterior`（矩阵 54.8 MB + 空间信息 8.8 MB）学**方法**——`Load10X_Spatial()` 的目录结构、`SpatialFeaturePlot()`、空间可变基因识别，这些操作与物种无关。**域内的空间研究作为阅读对象**：`GSE316219`（水稻根—AM 真菌共生的细胞分辨率图谱）是本专题最该读的那篇，它展示了空间数据在植物—微生物互作里能回答什么问题。

**这个折中要在课堂上说明白**：学生做完练习后要能回答"如果换成我的植物样本，`Load10X_Spatial()` 这一步会卡在哪"（答案：植物组织的切片与包埋、参考基因组与探针设计、叶绿体污染）。

## p03 宿主—病原双 RNA-seq

**出处**：`PRJNA661210` = `GSE157400`，Transcriptome analysis of the rice response to *Magnaporthe oryzae* identified core genes involved in immunity。

**设计（全因子，48 个样本）**：2 品种（`N3` / `Nip` 日本晴）× 2 处理（`G11` = Guy11 菌株接种 / `H2O` 模拟）× 4 时间点（12 / 24 / 36 / 48 hpi）× 3 生物学重复。

**课程取用**：`manifests/p03_runs.tsv` 里选了 **Nip × {G11, H2O} × {12, 24, 48} hpi × 3 重复 = 18 个样本**。舍弃 36 hpi 与 N3 品种是为了把下载量压到可接受范围；要做品种间抗感对比时把 N3 加回来即可（清单里改一行）。

**为什么它能做"双 RNA-seq"**：接种样本测的是**侵染叶片**，里面同时含水稻与稻瘟菌的转录本。讲义 ⑤ 的做法——把两个物种的转录本合并成一个 gentrome、做竞争性比对、再按来源拆分——正是处理这类数据的标准路径。**未接种的 `H2O` 组是关键对照**：它给出"交叉比对本底"，即在没有病原的样本里有多少读段被错误分配给了病原（讲义 ⑥ 要求把这个数字报出来）。

**必须知道的两件事**：

1. **本数据是单端（single-end）**。ENA 每个 run 只有一个 `.fastq.gz`。讲义 ⑤ 的 Salmon 命令要用 `-r` 而不是 `-1/-2`，STAR 也只传一个 fastq。**照抄双端命令会直接报错**。
2. **默认走流式截取**。全量 104 GB，脚本默认只取每个样本**前 200 万条 read**（约 2 GB 总量），做法是 `curl | zcat | head -n 8000000 | gzip`——传够就断开连接。**代价**：FASTQ 开头的 read 按 flowcell 位置排序，不是随机样本，质量与 GC 分布可能有偏，**绝对丰度类结论不可靠**。要做正式分析用 `--full` 下全量再 `seqtk sample`。这个取舍必须写进学生报告的方法学。

**参考基因组另备**：水稻 IRGSP-1.0（Ensembl Plants）+ 稻瘟菌 70-15（Ensembl Fungi），合并成 gentrome 并加 decoy，见讲义 ⑤ 5.1。

**自查判据**：`H2O` 对照样本里分配给稻瘟菌的读段比例应当**很低**（本底）；`G11` 接种样本的病原读段比例应随 hpi **单调上升**（12 → 48 hpi 病原生物量增加）。若对照组病原比例与接种组相当，说明 gentrome 或竞争性比对参数有问题，回查讲义 ⑨。

## p04 群体遗传学与群体基因组

**出处**：`PRJEB53625`，Study for genome-assisted Magnaporthe genetics（257 个 run 的稻瘟菌分离株集合）。

**课程取用**：`manifests/p04_runs.tsv` 选了 **40 个分离株**，筛选条件是 `base_count` 落在 0.4–1.5 Gb 之间——对应 40 Mb 的稻瘟菌基因组约 **11× 平均覆盖度**，合计下载 **12.5 GB**。分离株名如 `i56a`、`i44a`、`O23`。

**为什么 11× 就够**：稻瘟菌是**单倍体**，每个位点只有一个等位基因，不存在"杂合位点在低深度下被误判为纯合"这个二倍体的核心难题（讲义 ⑦ 与 `p05` 的 `--hwe` 讨论都要据此调整）。11× 对单倍体做 SNP calling 是可接受的；**但这一点必须写进方法学**，因为它同时意味着：`--hwe` 过滤在单倍体群体上没有意义，讲义 ⑤ 5.3 的四阈值里这一条要去掉或改用 DP/GQ 过滤。

**自查判据**：40 个分离株、单倍体、40 Mb 基因组，过滤后 SNP 数应在**十万量级**。PCA 前几个主成分若能把分离株分成可辨认的几群，与该项目"群体结构分析"的主题一致；若 PC1 只把一两个样本甩出去而其余挤成一团，优先怀疑那一两个样本的覆盖度或污染，而不是"发现了新群体"。

## p05 GWAS：Rice Diversity Panel 1（**本层最推荐的自学数据**）

**出处**：`http://ricediversity.org/data/sets/44kgwas/`，对应 Zhao 等 2011 年发表于 *Nature Communications* 的水稻多样性群体 GWAS 研究（**引用前请自行核验 DOI**——本课程只保证上述 URL 在 2026-08-30 实测可达，不代抄文献元数据）。

**实测规格**（已真实下载并核对）：

| 项目 | 实测值 |
|---|---|
| 个体数 | **413** 份种质（`sativas413.ped` 413 行） |
| 标记数 | **36,901** 个 SNP（`sativas413.map` 36,901 行） |
| 表型 | **36 列**性状数据（文件名叫 34traits，实含 36 列：多出的是两个 FT ratio 派生性状） |
| 基因型格式 | PLINK **`.ped/.map`**（不是 bed/bim/fam，需 `plink --file ... --make-bed` 转换） |
| 下载量 | 8.5 MB（另有 23 MB 的已发表 p 值可选） |

**为什么它是自学的最佳选择**：

1. **8.5 MB 就能跑完整条 GWAS 链**——质控、PCA、亲缘矩阵、MLM、曼哈顿图、后 GWAS，一台笔记本足够
2. **有published答案可对**：`RiceDiversity.44K.MSU6.GWAS_pvalues/MixedModel_Pval_all.txt`（23 MB）给出了**全部 36,901 个 SNP × 34 个性状的已发表 MLM p 值**。学生跑完 GEMMA 后可以直接与之比对——**这是自学场景下最稀缺的东西：一个可靠的参照答案**
3. 群体结构显著（籼稻 / 粳稻 / aus 等亚群），正是讲义 ⑦ 7.1「结构如何伪造关联」的活教材

**三个必踩的坑（已实测确认，写进讲义 ⑨）**：

1. **表型文件是旧 Mac 的 CR 行尾**（只有 `\r` 没有 `\n`）。`wc -l` 返回 **0**，R 的 `read.delim` 只读进一行。下载脚本已自动 `tr '\r' '\n'` 转成 `phenotypes_34traits.tsv`。
2. **ID 匹配要用第二列**：`.fam` 的 FID 是 HybID（如 `081215-A05`），**IID 是 NSFTVID**（如 `1`、`3`、`4`）；表型文件第 1 列是 HybID、**第 2 列才是 NSFTVID**。实测 `fam IID ∩ 表型第 2 列 = 413/413` 完全匹配，而与第 1 列交集为 **0**。按第一列去 merge 会得到一张空表——这正是讲义 ⑨-E2「表型文件格式」那一条的真实版本。
3. **`.ped` 里的表型列是 `-9`**（缺失）。必须用 `--pheno` 单独传入，不能指望基因型文件自带表型。

**自查判据**：以抽穗期（Flowering time）类性状为例，MLM 校正群体结构后应当能看到已知的强效应区间；λ 应接近 1。若 λ 明显大于 1.2，回查 PC 数与亲缘矩阵（讲义 ⑥ 6.1）。**与已发表 p 值的秩相关**应当很高——如果很低，先怀疑自己的表型列取错了（36 列里选错一列很常见）。

## p06 多组学整合（⚠ 有明确局限，务必读完再用）

**两层数据**：

| 组学层 | 来源 | 体系 |
|---|---|---|
| 转录组 | `GSE157400`（复用 p03） | 水稻 — 稻瘟菌侵染时序 |
| 代谢组 | `MTBLS13460`（MetaboLights） | 水稻 — 稻瘟菌免疫的苯丙烷代谢重编程（OsWRKY39） |

**必须讲清的局限：这两层不是同一批样本。** 它们来自不同实验室、不同实验、不同基因型材料。而 p06 的核心方法（WGCNA 的跨组学模块关联、MOFA2 的因子分解）**都要求样本一一配对**——这是方法的前提，不是可选项。

**因此本组合的正确用法**：

- ✅ **可以**：练习数据格式转换、缺失值处理、CLR/log 变换、WGCNA 建模块、MOFA2 跑因子分解——**所有流程操作**
- ❌ **不可以**：得出"某代谢物与某基因共变因而存在调控关系"这类**跨组学生物学结论**

**这个限制反而是本讲最好的教学素材**：p06 讲义 ④ 反复强调"整合之前先问样本是否配对"，而现成的公开数据恰恰经常不配对。作业里要求学生**主动指出这个缺陷**，并写出"如果这是我的课题，我会怎么设计采样使两层可配对"——这比在一份完美配对的数据上跑通 MOFA2 更接近真实科研。

**若要严格配对的数据**：需教师提供实验室自有的配对样本，或另找同时上传两层数据的研究。检索到的植物配对多组学研究多数只在文中声称配对，实际公开的往往只有一层。

**取代谢组矩阵**：MetaboLights 的研究目录里，`m_*.tsv` 是代谢物丰度表（MAF 格式），`s_*.txt` 是样本表，`a_*.txt` 是测定表。下载脚本会先拉回文件清单 JSON，再据此挑选。

## 注意事项汇总

1. **登录号必须核验**：`bash 06_data/verify_accessions.sh`。本课程已因此抓出一个假号——原 m01 讲义写的 `PRJNA294222` 在 ENA 与 NCBI 均查无此项（已改为 `PRJNA295606`）。**写材料前先核验，不要凭印象**。
2. **流式截取不是随机抽样**。p03 默认取前 200 万条 read，只用于跑通流程；正式分析用 `--full` + `seqtk sample`。
3. **数据不进 git**。`.gitignore` 已排除 `06_data/raw|processed|reference` 下的数据文件；下载默认落到 `<课程数据目录>/phd`，可用 `--outdir` 或环境变量 `NGS_DATA_DIR` 改到集群 scratch。
4. **外部链接会失效**。ricediversity.org 是 2013 年的静态站点，MetaboLights 与 GEO 的路径也可能改版。**每学期开课前跑一次 `verify_accessions.sh`**，并抽查几个直链。
5. **磁盘与配额**：p04 的 12.5 GB 与 p03 全量的 104 GB 都不要放家目录。
