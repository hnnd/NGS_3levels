## 一、这套数据是什么、为什么选它

**项目**：`PRJEB100987` — *Population structure analysis of west african Xanthomonas oryzae pv. oryzae*
**物种**：*Xanthomonas oryzae* pv. *oryzae*（Xoo，水稻白叶枯病菌），基因组约 **4.7 Mb**

选它的五条理由，每条都对应课程的一个硬约束：

| 理由 | 对应约束 |
|---|---|
| 基因组仅 4.7 Mb，4 核机器上 Flye 组装 **15–25 分钟**出结果 | u06/u08 要在课堂时段内跑完，真核大基因组不可行 |
| 同一批菌株**同时有 Illumina + ONT + PacBio** | u06 要求"长读长组装 + 短读长 k-mer 扫描"用**同一株**，否则估计值与组装结果没有可比性 |
| 项目内有 **57 株完成图基因组**（作者已发表） | u08 的泛基因组、建树、定种全都有现成输入；更关键的是**学生能把自己的组装和作者发表的同株完成图直接对比** |
| 水稻白叶枯是水稻主产区（含湖南）的重要细菌病害 | 与本院植保 / 微生物专业方向对口 |
| 全部数据 ENA 公开、无需申请 | **学生在校外也能自学**，不依赖实验室内网数据 |

> **与实验室数据的关系**：u08《学生实验操作手册》锚定的是实验室自测数据 `/data/lab/ngs/reads.fa`。
> 本数据集是**校外自学的等价替代**，走完全相同的 6 个模块与 12 个工具。
> 校内上课以手册为准；自学、补做、或想换一株再练一遍时用这套。

## 三、降采样方案

ONT 原始 63× 在 4 核机器上组装约 25 分钟。课堂演示建议降到 **40×**：

```bash
bash 06_data/undergraduate/download_ug.sh --run --subsample --depth 40
```

**为什么按碱基数而不是 read 数降采样**：长读长的 read 长度差异极大（几百 bp 到几十 kb），
按 read 数截取会得到一个偏向短读的子集，恰好丢掉最能跨重复区的那些长 read。
脚本按累计碱基数达到 `基因组大小 × 目标深度` 时停止。

**不要降到 30× 以下**：ONT 组装在 30× 以下会明显碎片化，学生会把"深度不够"误判成"参数没调好"。

## 四、怎么自查数据对不对

下载完先跑这几条，数字对不上就别往下做：

```bash
D=06_data/raw/undergraduate
# 1) md5 —— 脚本已自动校验，这里再确认一次
md5sum ${D}/reads/*.fastq.gz

# 2) ONT read 数与碱基数（期望 ≈ 38,078 条 / 302 Mb）
seqkit stats ${D}/reads/ERR15732384_ont.fastq.gz

# 3) Illumina 双端行数必须相等（不等 = 下载不完整）
[[ $(zcat ${D}/reads/ERR15732342_1.fastq.gz | wc -l) -eq \
   $(zcat ${D}/reads/ERR15732342_2.fastq.gz | wc -l) ]] && echo PAIRED_OK

# 4) 完成图长度量级（Xanthomonas 应在 4.6–5.1 Mb）
seqkit stats ${D}/genomes/*.fna ${D}/outgroup/*.fna
```

### 各步骤的预期结果区间

| 步骤 | 指标 | 预期 | 偏离说明什么 |
|---|---|---|---|
| GenomeScope（Illumina k-mer） | 基因组大小估计 | **4.4–4.9 Mb** | 明显偏大 → 污染或接头未去；明显偏小 → 深度不足或 k 值选得不当 |
| GenomeScope | 杂合度 | **≈ 0%** | 细菌是单倍体，杂合度应接近 0；显著非零 = 混合菌株或污染 |
| Flye / Canu 组装 | contig 数 | **1–5 条** | > 20 条 → 深度不足或降采样过头 |
| 组装 | 总长度 | **4.6–4.9 Mb** | 明显偏大 → 未去冗余（可能有单倍型重复） |
| QUAST（比对 `GCA_987216485`） | 总长差异 | **< 1%** | 差异大 → 组装漏段或引入了污染 |
| BUSCO（`xanthomonadales_odb10`） | Complete | **> 97%** | 偏低 → 组装不完整或注释库选错 |
| Prokka | 预测基因数 | **≈ 4,000–4,600** | 明显偏少 → 组装碎片化把基因截断了 |

### FastANI 的三档预期（本仓库实测）

用 MinHash（k=21，sketch 5000，与 Mash 默认一致）以 CIX4481 为查询算出的估计值：

| 比较对象 | 估计 ANI | 结论 |
|---|---|---|
| 项目内其余 11 株 Xoo | **99.83 – 99.95%** | 同种同致病变种 |
| *X. oryzae* pv. *oryzicola* HB8 | **97.87%** | **同种**，不同致病变种 |
| *X. campestris* pv. *campestris* CN02 | **87.10%** | 不同种 |

> **这三个数字本身就是 u08 的一个教学点**：ANI 95% 阈值把 Xcc（87%）判为异种是对的，
> 但把 Xoc（97.9%）判为**同种也是对的**——Xoo 与 Xoc 确实同属 *X. oryzae*，只是致病变种不同。
> **ANI 分得了种，分不了致病变种**。想区分 Xoo / Xoc 必须另找证据（效应子谱、致病性测定）。
> 大纲 §3.2 说的"95% 是经验分布的拐点而非自然常数"，指的就是这类情形。
>
> 上表是本仓库用 MinHash 估算的，**学生用 `fastANI` 跑出的值会有小数点后的差异**，
> 但三档的排序与相对间距稳定，可用作自查基准。
