## ① 任务背景

本讲内嵌了 1 学时的「非测序组学数据入门」（§4.1–4.5），理由写在讲义头部：**代谢组不是测序数据**——没有测序深度，有大量非随机缺失，特征身份靠数据库匹配而非比对确定。把它当成"另一个表达矩阵"直接做相关，网络会很好看，结论一条都站不住。

本次作业的核心数字是 **250 万**：5000 基因 × 500 代谢物的全相关矩阵有 250 万次检验，即使两个矩阵全是随机数，`p < 0.05` 下期望有 **12.5 万对"显著相关"**——足够画出一张任何布局算法都能画得很漂亮的网络。因此讲义 ⑦(1) 那句话是本作业的评分底线：**任何相关性网络在做多重检验校正之前都不是结果，只是一张图。**

第二条底线是 ⑦(4)：四项排除做完之后，**剩下的仍然只是"值得做实验验证的候选假说"**——共表达模块、MOFA 因子、hub 基因全部属于这一类。**作业与论文里都必须这样写**，把候选写成结论直接扣「方法选择与结果可信度说明」。

**评分表里「方法选择与结果可信度说明」占 30%**（契约 `rubric_requirements.method_justification`，p06 在 `stats_plugin_topics` 名单内）；「AI 使用与验证记录」占 10%（契约 `ai_verification_log`）。

## ③ 完成步骤

1. **转录组侧**（⑤ 步骤 1）：`vst(dds, blind = FALSE)`，**按方差而非均值**取 top 5000（WGCNA 找的是共变，恒定的高表达基因没有信息），最后 `t()`——WGCNA 要**样本 × 基因**，与 DESeq2 相反（⑨-E4）。
2. **代谢组侧**（⑤ 步骤 2）：跑 `06_metabolome_preprocess.R`。**先看 `missingness_vs_intensity.png` 再决定填补方式**——点云无趋势就不是 MNAR 主导，别一律左截断。脚本会同时输出"全部按均值填补"的朴素版本，**用它做敏感性分析并把结论差异写进 `sensitivity_imputation.tsv`**。
3. **顺序不能反**：过滤 → 填补 → CLR。CLR 对 0 与 NA 无定义（⑨-E7）；填补后仍有 0 则加明确伪计数（该特征最小非零值的一半）并**写进方法**。
4. **WGCNA**（⑤ 步骤 3）：`pickSoftThreshold()` 若 `SFT.R.sq` 达不到 0.8，脚本会**直接停下报错而不是硬跑**。**绝对不要把 β 硬调到 24/30 交差**——那样得到的模块是噪声，下游每一步都会继承它（⑨-E2）。
5. **参数要在看性状关联之前定下来**（⑦(3)）：`deepSplit` / `minModuleSize` / `mergeCutHeight` 三个旋钮**不能"调到结果好看为止"**，否则就是隐性多重比较。在 `scripts/` 里留下你的调参记录与定参时点。
6. **MOFA2**（⑤ 步骤 4）：`--seed` 必须给（变分推断有随机性）。方差分解若 Factor1 只在代谢组 view 上解释大部分方差且样本按进样批次排开，那是**批次因子**（⑥）。
7. **网络**（⑤ 步骤 5）：**全矩阵算完再 BH 校正**，不是先挑边再算 p（那是选择性推断，p 值在数学上已失效）。跑 `--n-perm 1000` 置换检验做整体校准——**若真实数据的边数落在置换分布内部，通过 FDR 的边整体上仍可能是噪声**。
8. **AI 任务（⑧）**：用讲义给的提示原文让 AI 写整合脚本，按四类错核查填 `ai_audit.tsv`：① 对组成性数据直接算 Pearson；② 把 MNAR 当 MCAR 填补；③ 无多重检验校正（或先挑边再算 p）；④ 把质谱强度当表达量处理。**某一类没犯也要写明"未犯，因为它做了 X"。**

### 「方法选择与结果可信度说明」的四个问题（契约 `method_justification`）

一页之内回答完：

| 要回答的问题 | 本专题的落点 | 不合格的写法 |
|---|---|---|
| **1. 为什么用这个检验 / 模型？** | 为什么用 Spearman 而非 Pearson；为什么 CLR；选 WGCNA 还是 MOFA2 还是晚期整合的理由（⑩ Q5） | "WGCNA 是常用方法" |
| **2. 为什么用这个阈值？** | β 的选择依据（**"使 SFT.R.sq 首次 ≥ 0.8 的最小 β"是一个约定，不是显著性检验**）；`--fdr 0.05`；`--qc-rsd 20`；三个模块旋钮的定值时点 | "网络显著符合无标度拓扑（R² = 0.85）"——这句话有两处错（⑩ Q1） |
| **3. 假阳性风险在哪？** | **写出你的检验总数与随机期望的"显著"对数**；置换检验的结论；填补方式制造的是假阳性还是假阴性（⑩ Q2）；批次/共同上游驱动有没有排除 | "做了 FDR 校正所以可靠" |
| **4. 什么证据能推翻你的结论？** | hub 基因从"网络中心"到"功能驱动者"的三条验证路径，各排除 ⑦(4) 四个来源中的哪几个（⑩ Q4）；`modulePreservation()` 或独立队列的结果 | "需要进一步验证" |

### 「AI 使用与验证记录」的评分口径（契约 `ai_verification_log`）

记录四要素：**用了什么提示（原文）** / **AI 给了什么** / **哪里错了** / **你是怎么发现的**。讲义 ⑧ 要求五件套：**提示词 + 错误定位（具体行号）+ 发现路径 + 修正版 + 两版结果差异**（改前改后各多少条边通过筛选、hub 列表重合多少、结论是否改变），外加一段 100 字以内的方法学说明。

> **发现路径是本任务真正的考核点**：是"我知道该查这四项所以去查了"，还是"跑完发现网络有 8 万条边才觉得不对"？**两种都算发现，但前者说明判据已经内化。**
>
> 只交"AI 错了"不给分。**未使用 AI 完成某一步时写明原因即可，不扣分；但通篇声称 AI 输出全部正确且无验证过程的，本栏不得分。**

## ⑥ 常见失分点

| # | 失分点 | 长什么样 | 怎么自查 |
|---|---|---|---|
| 1 | **把 counts/TPM 喂给 WGCNA**（⑨-E2，本讲头号坑） | `No power reached the desired scale-free topology fit index. Returning NA.`；R² 一路在 0.3–0.6 徘徊 | 90% 是这一条。回 ⑤ 步骤 1 用 `assay(vst(dds, blind = FALSE))` |
| 2 | **把 β 硬调到 24/30 交差** | 报告里 β = 30、R² = 0.46 却照常解读模块 | 那样得到的模块是噪声。按 ⑨-E2 逐条排除：输入矩阵 → 样本量 → 批次 → 混合组织 |
| 3 | **矩阵方向反了**（⑨-E4） | `Too many missing values in the data. All samples have been removed.`；或 `nSamples` 打印出 5000 | WGCNA 要样本 × 基因；`blockwiseModules()` 前加 `stopifnot(nrow(datExpr) == nrow(traits))` |
| 4 | **先挑边再算 p**（⑦(1)） | `which(abs(cormat) > 0.8)` 之后才做校正 | 这是选择性推断，p 值已失效。必须全矩阵算完再 BH |
| 5 | **模块-性状热图用未校正 p 值**（⑦(3)） | 照抄 WGCNA 官方教程那张图 | 12 模块 × 5 性状 = 60 次检验，必须 BH 校正、热图标 q 值 |
| 6 | **把软阈值当显著性检验**（⑦(2)） | "网络显著符合无标度拓扑（R² = 0.85）" | `SFT.R.sq` 不控制第一类错误、不判断任何一条边真假 |
| 7 | **CLR 之后出现 `-Inf`/`NaN`**（⑨-E7） | `In log(x) : NaNs produced` | 顺序反了。必须先过滤先填补再 CLR |
| 8 | **MOFA2 找不到 Python 后端**（⑨-E5） | `ModuleNotFoundError: No module named 'mofapy2'` | 在**同一个** conda 环境里装 `mofapy2`，并 `reticulate::use_condaenv(..., required = TRUE)` |
| 9 | **`cor` 被 tidyverse 遮蔽**（⑨-E6） | `unused arguments (weights.x = NULL, ...)` | 调用前 `cor <- WGCNA::cor`，跑完还原 |
| 10 | **把候选写成结论** | "该 P450 驱动了抗性表型" | 本讲能给出的最强结论是"**候选**"（⑦(4)）。用词直接影响第 5 节得分 |
| 11 | **样本量不足仍硬做 WGCNA**（⑨-E3） | 没有报错，但模块数每改一点参数就完全不同 | n < 15 时改用 MOFA2 或晚期整合；必须做时明确报告"n = X，模块结果为探索性结果"，并跑 `modulePreservation()` |
| 12 | **`conda install cytoscape`**（⑨-E1） | `PackagesNotFoundError: - cytoscape` | 桌面 Java 应用不走 conda。用 `r-igraph` 脚本化路径，或官网下载桌面版 |
