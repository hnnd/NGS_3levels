## ① 任务背景

讲义表头那句话是本次作业的全部标准：**跑出曼哈顿图不难，能在看图之前先判断这张图可不可信才是出口。**

因此本作业的评分顺序与分析顺序一致：**先 QQ、再 λ、最后曼哈顿**。报告里若先出现曼哈顿图的解读而没有 QQ 诊断，「完成度与结果正确性」直接按缺项计——因为整体膨胀与尾部抬升在曼哈顿图上**肉眼无法区分**，先看曼哈顿的人会把系统性膨胀造成的一片"信号"当成发现。

本讲**不重复** p04 讲过的 LD、HWE、群体结构原理，只考"怎么把它们用作协变量、用作阈值修正、用作候选区间边界"。

**评分表里「方法选择与结果可信度说明」占 30%**（契约 `rubric_requirements.method_justification`，p05 在 `stats_plugin_topics` 名单内）；「AI 使用与验证记录」占 10%（契约 `ai_verification_log`）。

## ③ 完成步骤

1. **取 p04 的交付清单**。缺 `ld_decay.txt` 就无法定候选区间宽度和 M_eff，缺 `pca.eigenvec` 就没有 Q 协变量——**先确认六项齐全再开工**。
2. **表型准备**（⑤ 5.2）：分布检查；多环境重复用混合模型剥掉环境效应后取一个值，**BLUE 与 BLUP 的选择必须给理由**（审稿人会问的第一件事）。H² < 0.2 的性状在几百个体上基本注定没有全基因组显著位点——**这时正确的动作是回去改表型测量精度，不是放宽阈值**。
3. **基因型质控**（⑤ 5.3）：四个阈值每个都要能说出理由，写进 `qc_thresholds.md`。注意 `--geno`（位点缺失率）与 `--mind`（个体缺失率）**作用对象不同**（`l1_p05` 考点）；**自交/克隆群体不能用 `--hwe`**（p04 §4.3）。
4. **Q 与 K**（⑤ 5.4）：GEMMA 的协变量文件**必须自带一列 1 作截距**，它不会替你加（⑨-E3）；K 用 LD 剪枝集算，不要用全标记集。
5. **两条路线 + PC 扫描**（⑤ 5.5）：**GLM 不校正的对照一定要跑**——用来展示校正到底做了什么。PC 数扫 0/2/4/6/10，画 λ–PC 曲线，取"**λ 接近 1 且信号未被抹平的最小 PC 数**"（⑦ 7.2；注意这是在两类错误之间找折中，不是单纯把 λ 压到 1）。
6. **先 QQ 后曼哈顿**（⑤ 5.7）：把 GLM 与各 PC 数的 QQ 画成一张拼图。**这一步不做，后面所有图都不值得看。**
7. **阈值**：`n_eff` 用 `wc -l < prune.prune.in`（来自 p04）或置换检验。**人类的 `5e-8` 不能直接搬到你的物种上**（④ 4.3）。同时给 genomewide 与 suggestive 两条线。
8. **候选区间与基因**（⑤ 5.8）：`--clump-field p_wald --clump-snp-field rs` **必须写**（PLINK 默认找 `P` 与 `SNP`，⑨-E8）；峰 ± LD 半衰距离扩成 BED（**0-based**，assoc/VCF 是 1-based，⑨-E9）。
9. **AI 任务（⑧）**：把 QQ 图（或分位数数据）与 λ 交给 AI 问"为什么偏离对角线"，**第一轮不说明模型、PC 数、样本量**。按五条核查填 `ai_audit.tsv`，并**按它的建议重跑**，把前后 QQ 与 λ 并排对比。

### 「方法选择与结果可信度说明」的四个问题（契约 `method_justification`）

一页之内回答完：

| 要回答的问题 | 本专题的落点 | 不合格的写法 |
|---|---|---|
| **1. 为什么用这个检验 / 模型？** | 为什么用 MLM（Q + K）而不是 GLM；K 与 Q 各吸收哪个尺度的混杂；用了 FarmCPU/BLINK 的话为什么要给 MLM 对照 | "MLM 是标准做法" |
| **2. 为什么用这个阈值？** | M_eff 怎么估的（剪枝集行数 / simpleM / 置换）；为什么不用人类的 `5e-8`；genomewide 与 suggestive 各自的下游用途 | "用了 5e-8" |
| **3. 假阳性风险在哪？** | λ 的读法（只用中位数、随 n 与多基因性上升）；**过度校正的假阴性风险**——与结构共线的真信号会被 K 一起吸收；孤峰的分型错误风险；`--clump-p1` 有没有被调大来制造结果 | "λ 接近 1 所以没问题" |
| **4. 什么证据能推翻你的结论？** | 换模型后峰位置是否稳定；换随机种子（FarmCPU/BLINK）能否重复；若做 CRISPR 敲除，你预期哪个位点最可能不重复，为什么 | "需要进一步验证" |

### 「AI 使用与验证记录」的评分口径（契约 `ai_verification_log`）

记录四要素：**用了什么提示（原文）** / **AI 给了什么** / **哪里错了** / **你是怎么发现的**。本次落点是讲义 ⑧ 的五条核查：

| # | 核查点 | 越界/不足的表现 |
|---|---|---|
| ① | 有没有**区分整体抬升与尾部抬升** | 笼统说"偏离说明有关联信号"，不分两种形态 |
| ② | 有没有**追问模型与校正** | 不问 GLM/MLM、几个 PC、K 怎么算的、样本量多大 |
| ③ | 有没有把 **λ 的经验区间当绝对标准** | "λ = 1.15 属于正常范围，不用处理" |
| ④ | 它的**建议在你的数据上是否有效** | **按它说的重跑**，重跑前后 QQ 与 λ 并排对比 |
| ⑤ | 有没有提示**过度校正的风险** | 一味建议"多加几个 PC" |

**必须给出判定**：它的建议是"改善了模型"还是"只是把信号一起抹平了"——**用 λ 与显著位点数两个指标同时说明**。若它在追问后改口，记录改口前后的差异。

> 只报告"AI 错了"不给分。**未使用 AI 完成某一步时写明原因即可，不扣分；但通篇声称 AI 输出全部正确且无验证过程的，本栏不得分。**

## ⑥ 常见失分点

| # | 失分点 | 长什么样 | 怎么自查 |
|---|---|---|---|
| 1 | **先看曼哈顿图** | 报告第 3 节的解读写在第 2 节之前，或干脆没有 QQ 图 | 整体膨胀与尾部抬升在曼哈顿图上肉眼无法区分。顺序是逻辑必需，不是习惯 |
| 2 | **表型文件格式**（⑨-E2，本讲最高频） | `Line 1 of --pheno file has fewer tokens than expected.` | PLINK 要 **FID IID 表型**三列：`awk '{print $1,$1,$2}'`。**GEMMA 不读 `--pheno`**，读 `.fam` 第 6 列，须按 `.fam` 行序 |
| 3 | **协变量文件缺截距列**（⑨-E3） | β 与 p 值大面积漂移，或 GEMMA 直接报协变量矩阵的错 | GEMMA 的 `-c` 文件必须自带一列全 1，它不会替你加 |
| 4 | **分析个体数为 0**（⑨-E4） | `## number of analyzed individuals = 0` | `.fam` 第 6 列全是 `-9`，或表型行序错位；`awk '{print $6}' gwas.fam \| sort \| uniq -c` 先看一眼 |
| 5 | **找不到 GEMMA 输出**（⑨-E5） | 无报错，当前目录什么都没有 | 默认写进 `./output/`；`-o` 只是文件名前缀不是路径 |
| 6 | **报告的标记数与 GEMMA 实际分析数不符**（⑨-E6） | `## number of analyzed SNPs` 明显小于 `wc -l gwas.bim` | GEMMA 在 PLINK 过滤之上还有自己的默认过滤；**报告的标记数必须是 GEMMA 日志里的那个** |
| 7 | **显著位点表只有 p 值** | 无 MAF、无 β 与 SE、不写 p 值类型 | 无法判断结果是否可用。必备列：SNP、chr、pos、等位基因、MAF、β 与 SE、p 值类型、候选区间、区间内基因数 |
| 8 | **`--clump` 缺列名参数**（⑨-E8） | `Error: No significant --clump results.` 或提示缺 P/SNP 列 | GEMMA 输出的是 `p_wald` 与 `rs`，必须写 `--clump-field p_wald --clump-snp-field rs`；**不要靠调大 `--clump-p1` 制造结果** |
| 9 | **`bedtools intersect` 返回空**（⑨-E9，不报错） | 输出文件 0 行 | 染色体命名不一致（`Chr01`/`chr01`/`1`）或 0/1-based 错位；`cut -f1` 两侧 `sort -u` 对照 |
| 10 | **孤峰当成发现** | 单 SNP 极显著、邻居 p 值毫无起色，直接写进结论 | 在 LD ≠ 0 的区域这是**反常的**；先查该 SNP 的 HWE、缺失率、等位平衡，IGV 看比对（⑥ 6.2） |
| 11 | **反复换模型直到出现显著位点**（⑨-E10） | 报告里只留下了"有结果"的那次 | 那是用随机性制造结果。小样本时应承认限制并给功效讨论 |
| 12 | **图里出现方块字** | 中文标题在集群 R 环境下渲染为 □□□ | 课程规则：图内一律英文 |
