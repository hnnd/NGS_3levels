## ① 任务背景

双 RNA-seq 的两个坑都**不报错**：交叉比对给病原侧计数带来的虚增，和把两个物种合起来算 TPM/size factor 带来的方向性偏移。两者产出的结果表都完整、图都好看，只有把分母和本底算清楚才看得出问题。讲义 ⑧ 那句话是本次作业的判据：**考的不是 AI 会不会错，而是你能否在它给出一份格式完美、命令可执行的答案时看出它错了**——对你自己的流程同样适用。

本作业承接硕士 m04 §4.3（差异表达）与 m02 §4.5（比较基因组与直系同源），经 `l1_p03` 送达。**这两节讲过的内容本作业一律不重复考**，只考"把它们放进互作场景后从哪里开始失效"。

产出的候选效应子排序表与 ⑩ Q7 的设计草案**可直接作为 p08 课题设计的素材**——现在认真做等于提前开工。

**评分表里「AI 使用与验证记录」占 10%**（契约 `ai_verification_log`，博士层全部作业强制）。p03 不在 `stats_plugin_topics` 名单内，因此**没有**独立的「方法选择与结果可信度说明」评分栏；相应的判断能力由「判断与讨论质量」（28%）承载。

## ③ 完成步骤

1. **装两个环境外工具**（讲义 §5.1）：SignalP 6.0 需 DTU 学术许可（在线申请后 `pip install signalp-6-package/`）；EffectorP 3.0 从 GitHub clone。**申请不到许可时**改用 Phobius / DeepSig，跨膜排除改用 DeepTMHMM 在线服务——**替代工具必须在方法学里写明，它们与 SignalP 的结果并不等价**。
2. **构建加前缀的双参考**（§5.2）。**改了 FASTA 却没同步改 GTF 第 1 列是最高频的错**；合并后第一件事跑 `samtools faidx` 让它替你查重名（⑨-E1）。
3. **竞争性比对与拆分**（§5.3）。`--outFilterMultimapNmax 1` 只保留唯一比对，**被剔除的量必须统计并随时间报告**。`ReadsPerGene.out.tab` 第 2/3/4 列选哪一列由文库链特异性决定，选错得到一份几乎全是噪声的矩阵。
4. **算本底**：未接种对照那一行的病原占比就是这套流程的交叉比对本底，写进 `crossmap_background.txt` 与方法学。**没有未接种对照的同学**按 ⑩ Q2 写清你还能问哪些问题、必须放弃哪些结论。
5. **分开归一化 + 时序 LRT**（§5.4）：两个独立的 `dds`，**不要合并**。病原侧早期大量 0，默认 size factor 估计会报错，用 `type = "poscounts"`（⑨-E3）——**不要**用 `rowSums > 0` 草草了事。
6. **先看诊断图再看 p 值**：`fig2` 不看，后面所有 p 值都不值得信（⑥ 6.2）。
7. **效应子三步 + NLR 扫描**（§5.5）：SignalP → 跨膜排除 → EffectorP，**跨膜排除要做在成熟肽上**，不是全长（§4.7、⑨-E8）。物种特异基因两个来源都要取（孤儿基因 + 只有目标菌株计数 > 0 的 orthogroup），取完用 `tblastn` 回查复核。
8. **AI 任务（⑧）**：用讲义给的提示原文提问（**不要预先提示它注意什么**），按四条核查填 `ai_audit.tsv`。

## ⑥ 常见失分点

| # | 失分点 | 长什么样 | 怎么自查 |
|---|---|---|---|
| 1 | **改了 FASTA 没同步改 GTF**（⑨-E1） | `Fatal INPUT FILE error, no valid exon lines in the GTF file`；或更糟——工具遇重名静默取第一条，看起来正常却丢了半个基因组 | `cut -f1 dual.gtf \| grep -v '^#' \| sort -u` 与 `grep '^>' dual.fa \| cut -c2- \| cut -d' ' -f1 \| sort -u` 两个集合必须一致 |
| 2 | **病原侧 size factor 估不出来**（⑨-E3，本讲最高频） | `every gene contains at least one zero, cannot compute log geometric means` | 用 `estimateSizeFactors(dds_p, type = "poscounts")`，或限制在占比达标的时间点并写明剔除判据 |
| 3 | **两物种合起来算 TPM / 同一个 dds** | 不报错，宿主 TPM 被病原生物量变化伪装成趋势 | 必须两个独立 `dds`（§4.4）。报告第 3 节要写出错的方向 |
| 4 | **把病原占比当协变量放进模型**（⑨-E4） | `the model matrix is not full rank` | 占比与 `time` 高度共线，数学上无解；改走 spike-in 归一化或 in planta vs in vitro 的 Wald 检验 |
| 5 | **STAR 内存不足**（⑨-E2） | `not enough memory for BAM sorting` | 双参考索引远大于单物种；`qsub -l h_vmem=64G`，且 `--limitBAMsortRAM` 必须**小于**申请值 |
| 6 | **效应子候选异常多**（⑨-E8，不报错） | 三千个以上 | 多半把**全长序列**（含信号肽）喂给了 EffectorP。`seqkit fx2tab -l -n mature_peptides.faa \| head` 核对成熟肽应比全长短 18–30 aa |
| 7 | **OrthoFinder 某菌株特异基因数高出数倍**（⑥ 6.5） | 当成生物学发现写进报告 | 几乎一定是注释流程不一致，先统一重注释再解释 |
| 8 | **LRT 结果按 `log2FoldChange` 排序** | 报告里写"上调最多的前 20 个基因" | LRT 下它只是某一对比较的附带值，不是被检验的量；按表达模式聚类（⑥ 6.3） |
| 9 | **去 conda 装 SignalP / TMHMM**（⑨-E6） | `PackagesNotFoundError: - signalp` | 两者受 DTU 许可约束，按 §5.1 申请；用替代工具须在方法学写明 |
