# 预期组图骨架 · Fig.1–Fig.6 模板

> **本文件是填空骨架，不单独计分。** 评分标准见同目录 `phd_proposal.md` ④（组图骨架计入「技术细节」与「汇报表达」）。
> 用法：复制本文件为 `figure_skeleton.md`，填满六格并做"因此"检验，
> 用 `make_placeholder_figs.R` 画出带假数据的占位图，一并导出为 `figure_skeleton.pdf`。
>
> ⚠ **课程作图硬规矩：所有图中不出现中文字符。** 图题、轴标签、图例、注释一律英文；
> 中文解释写在本文件的论点栏与正文里。Linux 下 R / matplotlib 默认字体不含中文字形，
> 导出的 PDF 里是方块或缺字，而**屏幕预览时可能看起来正常**（讲义 ⑨-3 有真实报错）。

## ① 任务背景

**组图骨架是方案的验收标准，不是方案做完之后才画的东西。**

一篇研究论文的组图不是结果的陈列，是**论证的骨架**（讲义 ④4）。典型的六图结构：

```
Fig.1  建立现象      →  "存在一个值得解释的观察"
Fig.2  刻画范围/特征  →  "因此，这个现象具有 XX 特征"
Fig.3  提出机制候选  →  "因此，可能由 Y 介导"
Fig.4  提供因果证据  →  "因此，扰动 Y 会改变现象"（遗传/药理/互补）
Fig.5  排除替代解释  →  "因此，不是 Z 导致的"
Fig.6  收束为模型    →  "综上，机制是 …"
```

**如果你现在就画不出这条链，说明方案里至少有一环没想清楚**——不是"图还没画"，是"论点还不存在"。先画得出组图骨架，再去测序，能省掉的往往是半年。

**为什么要求画占位图而不是手绘草图**：占位图（用假数据跑 `ggplot2`）比手绘更容易暴露"这个论点其实画不出来"——你会在写 `aes()` 的时候发现自己根本没有那一列数据。

> **论点栏的检验**：把它读出来。如果是"X 的表达热图"，这张图还没有论点；如果是"处理组在 24 h 特异激活了 JA 通路，n=3，双侧 Wilcoxon，误差棒为 SEM"，它有。
>
> **图型栏的检验**：图的类型由**论点**决定，不由数据类型决定。同一份表达矩阵——论点是"两组整体可分"就画 PCA；论点是"某通路被特异激活"就画该通路的基因集打分箱线图；论点是"响应随时间推移"就画时序折线。**"我有表达矩阵所以画热图"是典型的技术驱动作图。**

| Fig.3 → Fig.4 |  |  |  |
| Fig.4 → Fig.5 |  |  |  |
| Fig.5 → Fig.6 |  |  |  |

三种症状与对策：

| 症状 | 诊断 | 对策 |
|---|---|---|
| 插不进"因此"，只能插"另外" | 两张图是并列的结果，不是递进的论证 | 合并成一张多 panel 图，或把其中一张移进补充材料 |

## ④ 评分标准

**本文件是模板，不单独计分**；评分见同目录 `phd_proposal.md` 的 ④ 评分标准。组图骨架的得分落在两处：「技术细节」（六格填满、通过"因此"检验）与「汇报表达」（**组图骨架必须讲**，占 8 分钟汇报中的 2 分钟）。

**交稿前自查（逐条打勾）**

- [ ] 六格全部填满，没有一格写"待定"
- [ ] 每条论点都是**可被证伪的陈述句**，不是"…的热图 / …的分布"
- [ ] 每张图的"数据来自路线图第几步"都能对到 `proposal.pdf` §4 的节点编号
- [ ] 五个相邻对全部做过"因此"检验，不通顺的给了对策
- [ ] **有一张图在排除替代解释**（Fig.5 位不能空着——这是"组图不成链型"的通病）
- [ ] 每条图注都含 n、统计方法、误差棒定义
- [ ] 审稿人六项清单逐图检查过
- [ ] 没有出现四个反模式：柱状图+误差棒表示连续分布 / 双 Y 轴 / 热图不给聚类依据 / 只有 p 值没有效应量

- [ ] **图中没有任何中文字符**
- [ ] 已标出"我最没把握的是哪一张、为什么"（讲义 ⑩-7④）

## ⑥ 常见失分点

| # | 失分点 | 长什么样 | 怎么自查 |
|---|---|---|---|
| 1 | **组图不成链**（讲义 ⑥ 反例二） | Fig.1 PCA → Fig.2 火山图 → Fig.3 GO → Fig.4 KEGG → Fig.5 热图 → Fig.6 qPCR。看起来完整，实际是一条标准分析流程的输出顺序 | 相邻两图只能插"另外"；且**没有任何一张图在排除替代解释** |
| 2 | **论点栏写成图的描述** | "候选基因表达热图"（⑨-5 评审原话：「这张图想说什么？」） | 论点必须是可被证伪的陈述句 |
| 3 | **图注三要素缺失**（⑨-7） | n、统计方法、误差棒定义缺一即触发，是最容易避免也最常被扣分的失误 | 用步骤 3 的模板逐图套一遍 |
| 4 | **柱状图 + 误差棒表示连续数据** | 均值 ± SD 掩盖双峰、离群与实际 n；不同的原始分布能画出同一根柱子 | 改成点图 / 箱线图叠加原始点；**n 小时必须显示每个点** |
| 5 | **双 Y 轴** | 两条轴的缩放是任选的，"趋势一致"可以被人为制造 | 拆成上下两个共享 X 轴的 panel |
| 6 | **热图不给聚类依据** | 距离度量、聚类方法、是否按行标准化都会改变图案 | 图注写清 scale（行 Z-score？）、距离、聚类方法 |
| 7 | **只有 p 值没有效应量** | 样本量足够大时任何微小差异都显著 | 同时给效应量（log2FC、Cohen's d）与置信区间 |
| 8 | **"数据来自第几步"填不出来** | 这不是填表偷懒，是**路线图缺了一步** | 回 `phd_proposal_template.md` §4 补节点，不要在这里硬凑 |
| 9 | **占位图脚本跑不起来** | `Cannot find directory 'figures'`（⑨-4）；或 `Aesthetics must be either length 1 or the same as the data`（⑨-2，分组向量长度与数据行数不一致） | 脚本开头 `dir.create(..., recursive = TRUE)`；把分组放进数据框用 `aes(fill = group)`，不要在 `aes()` 外传裸向量 |
| 10 | **图里出现方块 / 缺字**（⑨-3） | `conversion failure on '处理组' in 'mbcsToSbcs'`；屏幕预览正常，导出 PDF 才发现 | 交稿前把 PDF 放大到 400% 逐图看一遍 |
