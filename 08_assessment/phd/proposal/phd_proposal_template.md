这份模板对应讲义 `02_lectures/phd/topic08_project_design/08_project_design_lecture.md` ⑤ 的步骤 1–4，把"课题分析方案"拆成七节。

**为什么给模板而不是让你自由发挥**：方案评审只问四个问题——科学问题清不清晰、方法合不合理、数据够不够、验证可不可行（讲义 ④6）。这七节是这四个问题的最小完整覆盖。自由发挥的方案最常见的缺失不是写得不好，而是**整节漏掉**：漏掉数据清单的批次信息、漏掉每个推断节点的统计依据、漏掉 Plan B。模板让"漏掉"变得可见。

**填写顺序建议**：§1 → §3 → §4 → §2 →§5 → §6 → §7。先把问题和数据锁死，再去补文献背景——反过来做的人容易把文献里别人的问题当成自己的问题。

## ③ 完成步骤

以下七节即书面方案正文。**逐节填写，不要改变节的顺序与编号。**

### §1 科学问题与假说

> **这一节要回答什么**：你要解决的未知是什么，以及回答它之后谁会改变做法。
>
> **填写要点**：必须写成"已知 ___，但不知道 ___"的形式；再加一句"如果 ___ 被回答，谁会因此改变做法"。假说要可证伪——写成"我预期 X 会导致 Y，若观察到 Z 则假说被推翻"。
>
> **常见写法错误**：① 写成研究方向（"研究 X 病原的致病机制"）而不是具体未知；② 写不出"已知 A"说明文献没读够；③ 假说不可证伪（"探究…的作用"）；④ 科学问题实际是"我想用这个技术"——这是评审的三个致命伤之首。

**填写区**

- 已知：
- 但不知道：
- 假说（可证伪形式）：
- 若被回答，谁会改变做法：
- **为什么必须用组学**（而不是 qPCR / 表型观察 / 已发表数据的重分析）：

### §2 已有证据与空白

> **这一节要回答什么**：支持你假说的现有证据有哪些，缺口在哪里。
>
> **填写要点**：按"证据 → 它支持假说的哪一部分 → 它的局限"三列列出，含你课题组未发表的预实验数据。空白要指向 §1 的"但不知道"。
>
> **常见写法错误**：① 写成文献综述（把整个领域讲一遍），本节只要**与你的假说直接相关**的证据；② 只列支持假说的证据，不列与之矛盾的——矛盾证据恰恰是评审最想听的；③ 引用未经核实的文献（DOI 核查方法见讲义 ⑧，AI 生成的引用必须逐条查）。

|---|---|---|
|  |  |  |

- 与假说矛盾或不一致的证据：
- 由此确定的空白：

### §3 数据策略

> **这一节要回答什么**：你要用什么数据，够不够，从哪来。
>
> **填写要点**：数据清单每行一类数据，八栏填全。**「深度依据」一栏不许写"参考文献常用"**——写清是按什么算出来的（转录本检出率？变异检出功效？覆盖度？）。样本量必须有依据：功效计算、同类研究的效应量、或可得样本上限；**写"依据可得样本上限"是诚实且可接受的，不写任何依据不可接受**（讲义 ⑦ 动作 1）。
>
> **常见写法错误**：① 样本量按经费而非功效决定且方案对此只字不提（评审三大致命伤之二）；② 技术重复冒充生物学重复；③ 批次信息缺失——批次与处理完全混杂时模型无解，这一点在硕士 m04 ⑨-E5 有真实报错；④ 数据存放位置写"在我电脑上"，合作方接不了手。

**填写区**

| 数据类型 | 样本数 | 分组与重复 | 时间点 | 测序策略与深度 | **深度依据** | 已有 / 待产出 | 批次信息 | 存放位置 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

- 样本量依据（功效计算 / 同类效应量 / 可得上限，三选一并说明）：
- 数据获取路径（自测 / 公共数据 / 合作）及其代价：
- **能不能先用公共数据把假设验一遍？**（讲义 ④1 问题三：一周的重分析常常能改掉一个错误的测序方案）
- 合作数据的权属与作者顺序是否已谈清：

### §4 分析路线与统计依据

> **这一节要回答什么**：从原始数据到结论，每一步做什么、用什么、结果不对时长什么样。
>
> **填写要点**：先画技术路线图（DAG，源文件随交付物提交），再用下表把每个节点写全。**技术路线图和 Nextflow / Snakemake 的 DAG 是同一个东西的两种画法**（p07 ④2），所以三条病也一样：某步输入说不清从哪来 = 该节点没有入边；两条支线拼不起来 = 两个连通分量；每步都要"看结果再定下一步" = 全串行、无法估工期。
>
> **统计依据表是本节的硬要求**：路线图上每个涉及 p 值的节点都要有这一栏，**空栏的方案不予评审**。各专题的落点：差异表达 → p02/p03 与硕士 m04；群体结构与 LD → p04；关联分析的群体结构校正与 QQ 图 → p05；相关网络的多重检验与"相关不等于因果" → p06；通用统计 → `l0_06_stats`。
>
> **常见写法错误**：① 节点只写工具名不写版本与关键参数；② 缺"结果不对时长什么样"一栏——这是全课程 ⑥ 训练在方案阶段的应用；③ 没标出哪些节点必须等全部样本到齐（它们决定了最早出结果的时间）；④ 统计依据栏写"用 DESeq2 做差异分析"，那是工具不是依据。

### §5 风险与备选方案

> **这一节要回答什么**：最可能在哪一步失败，失败了具体怎么办。
>
> **填写要点**：**至少两个 Plan B，且必须具体到能立刻执行**——不是"换一种方法"，而是"若边缘区差异基因少于 50 个，转为 LMD + bulk RNA-seq 提高深度"。写 Plan B 的过程本身会暴露主路线的脆弱环节。
>
> **常见写法错误**：写"如遇问题及时与导师沟通"（评审三大致命伤之三）。判据：指着路线图上耗时最长的那一步问"它失败了你怎么办"，答不出具体动作即不合格。

|---|---|---|---|---|

### §6 时间表

> **这一节要回答什么**：什么时候能拿到什么。
>
> **填写要点**：里程碑对齐 §4 里"必须等全部样本到齐"的节点——它们是关键路径。给出每个里程碑的**可交付物**，不是"完成分析"这类无法验收的说法。
>
> **常见写法错误**：① 时间表与 §3 的"待产出"数据不一致；② 没有为 Plan B 留时间；③ 里程碑不可验收。

### §7 预期产出

> **这一节要回答什么**：这个方案做完，能产出什么，写成什么样的论文。
>
> **填写要点**：与组图骨架（`phd_figure_skeleton_template.md`）对应——每个预期产出应当能落到 Fig.1–Fig.6 的某一格。**并回答那个不留情面的问题：如果方案全部做完但结果全是阴性，这篇论文还能写吗？写什么？**
>
> **常见写法错误**：答不出阴性结果的写法，说明方案的价值全部押在一个未知的结果上——**这是设计缺陷，不是运气问题**（讲义 ⑩-7⑥）。
