## 参考答案与评分要点

> **计分规则重申：完成即给分、不按对错计。** 下面的答案供你自查用——对照后把不会的那一块记下来，按 `l1_phd.md` 的「最短补课路径」补完，比答对更重要。

**Q1（`l1_p04`）** 1) CHROM、POS、ID、REF、ALT、QUAL、FILTER、INFO。2) `GT:AD:DP:GQ` 是 FORMAT 列，声明后面每个样本列各字段的顺序与含义，二者按冒号一一对应。3) `0/1` 杂合（一条 REF 一条 ALT）；`1/1` ALT 纯合；`./.` 缺失（该个体该位点未做出判读）；`0|1` 与 `0/1` 基因型相同但**已定相**（phased，知道哪条单倍型带哪个等位基因）。4) AD 是各等位基因的支持读段数，18+15=33=DP。`AD=2,1 / DP=3` 深度过低，杂合判读不可信——3 条读段无法区分真杂合与测序错误，这类位点应被 `--minDP` / `GQ` 过滤掉。
**自查点**：答不出 FORMAT 与样本列的对应关系 → 回 m03 §5.1、§5.2。

**Q2（`l1_p04`，上机）** 无标准答案，看真实产出。合格产出应含：样本数、`0/0`/`0/1`/`1/1`/`./.` 四类计数与比例。第 3 问要点：缺失率高（>20%）先查是**位点层面**还是**个体层面**的缺失——用 `--missing-indv` / `--missing-site` 分别看，先剔除极端缺失的个体，再按位点过滤；顺序反了会误删好位点。报错常见于未建索引（`bcftools index`）或文件是普通 gzip 而非 bgzip。

**Q3（`l1_p05`）** `--maf 0.05` 剔除次等位基因频率 < 5% 的位点（低频位点在 GWAS 中检验功效极低且假阳性高）；`--geno 0.1` 剔除**位点**缺失率 > 10% 的 SNP；`--mind 0.1` 剔除**个体**缺失率 > 10% 的样本；`--hwe 1e-6` 剔除严重偏离 HWE 的位点。1) 前者作用于位点（列），后者作用于个体（行）。2) 全基因组几十万到几百万个位点同时做 HWE 检验是海量多重检验，用 0.05 会误删大量真位点；1e-6 是经验上的保守阈值。另外群体结构会通过 Wahlund 效应造成系统性偏离，**应先分群再检验**。3) 60 个二倍体个体 = 120 条染色体，MAF 0.05 即至少 6 条；小样本下应**调高**（如 0.05→0.1），因为低频等位基因的频率估计本身不稳。
**自查点**：说不出 `--geno` 与 `--mind` 的差别 → 回 m03 §5.1 与 p05 大纲实践表。

**Q4（`l1_p05`）** 正确：**A、B、E**。C 错——VCF 位点转 BED 应写 `start=POS-1`、`end=POS`；D 错——`bedtools` 不做跨格式的坐标推断，它假定输入都已是 BED 约定。为什么关心：p05 后 GWAS 用 `bedtools intersect` 把候选区间与注释 GFF 取交集，坐标偏移一个碱基不会报错，但会在区间边界处漏掉或多算基因，而这类错误在下游候选基因排序里看不出来。

**Q5（`l1_p03`）** 1) 泊松假定均值=方差，只适合技术重复；生物学重复引入个体间变异，使方差 > 均值（**过离散**），负二项在泊松上多一个离散度参数来吸收这部分。2) `~ batch + condition` 在估计 condition 效应时把 batch 作为协变量一并放进 GLM，扣除批次的系统性偏移；`~ condition` 则把批次差异算进残差，降低检验功效甚至造成假阳性。3) LRT 比较完整模型 `~ time` 与缩减模型 `~ 1`，回答的是「**该基因的表达是否随时间发生了任何变化**」——它给出时序响应基因集合，不指认具体哪两个时间点不同。4) size factor 由各样本 counts 的中位数比值（median-of-ratios）估计，前提是**大多数基因不差异表达**。侵染过程中病原生物量随时间大幅上升，合表后这个前提被彻底破坏，size factor 会把生物量变化当成文库大小差异吸收掉，宿主与病原的真实表达变化都被扭曲。
**自查点**：第 4 问答不上来 → 回 m04 §3.2 归一化/标准化。

**Q6（`l1_p03`）** 1) ortholog：分歧事件是**物种形成**；paralog：分歧事件是**基因复制**。2) RBH 只看序列相似度最高，遇到基因复制后一方丢失、进化速率差异大、或存在多拷贝基因家族时会把 paralog 判成 ortholog；它也无法处理一对多、多对多的直系同源关系。3) `Orthogroups.GeneCount.tsv` 是各 orthogroup 在各物种中的基因数矩阵，用于泛基因组划分与基因家族扩张收缩分析；`Single_Copy_Orthologue_Sequences/` 是所有物种各含且仅含一个成员的 orthogroup 序列，用于建物种树（避免旁系同源污染树拓扑）。4) 物种特异行 = 只有一列非零、其余物种全为 0。证据强度上限：这只是「基因含量差异」这一条相关性证据，能提出**假设**（该基因可能与该菌株的毒力/宿主范围有关），不能证明机制；p03 会要求与时序表达、分泌信号预测取交集后再排序，且预测仍需实验验证。

**Q7（`l1_p06`）** 1) `baseMean` 全样本归一化后的平均表达量；`log2FoldChange` 以 2 为底的倍数变化（通常已收缩）；`lfcSE` 该估计的标准误；`stat` Wald 统计量（或 LRT 统计量）；`pvalue` 原始 p 值；`padj` BH 校正后的 p 值。2) ① 独立过滤：低表达基因被剔出多重检验以提高整体功效；② Cook's distance 离群检测把受单个样本主导的基因置 `NA`。处理：筛选时写 `!is.na(padj) & padj < 0.05`，**绝不把 `NA` 当成不显著混进统计，更不能当显著**。3) `counts()` 原始或归一化计数（离散、异方差），用于重新建模；`vst()` 方差稳定化变换，快、适合大样本；`rlog()` 正则化 log 变换，小样本（n<30）更稳；后两者输出连续、近似同方差的矩阵，是 PCA、聚类、热图、**WGCNA、MOFA2** 的正确输入。4) counts 的方差随均值剧增，高表达基因主导相关结构，`pickSoftThreshold` 的无标度拟合 R² 上不去（曲线平坦或震荡），选不出合理的 β。

**Q8（`l1_p06`，上机）** 无标准答案。要点：`pvalue` 筛出的基因数会**明显多于** `padj`，差值就是多重检验校正拦掉的假阳性——这正是 p06「250 万个相关检验」问题的同一逻辑。`padj` 为 `NA` 的比例通常可达 20%–50%（取决于低表达基因占比），属正常。若你的列号与示例不同却直接照抄命令，得到的数字无意义——**核对列号本身就是这道题在考的能力**。

**Q9（`l1_p07`）** 1) input：两个 FASTQ + 索引目录；output：`quant/{sample}/quant.sf`；threads：8；log：`logs/salmon/{sample}.log`。2) `{sample}` 是 wildcard（通配符），取值由**下游需求倒推**——`rule all`（或其他 rule 的 input）声明了需要哪些 `quant/XXX/quant.sf`，Snakemake 用 output 模式反向匹配出 `sample=XXX`。3) 12 个任务；它不是「知道有 12 个样本」，而是 `rule all` 里列了 12 个目标文件，DAG 展开出 12 个 job。4) `{input.r1}` 来自 rule 的 input 声明（已经是展开后的具体路径）；`{wildcards.sample}` 直接取通配符的值本身——当你要的是「样本名」而不是「某个已声明的文件路径」时用后者。5) output 去掉通配符后，Snakemake 无法从目标文件反推 `{sample}` 的值，而 input 里仍有 `{sample}`，会报 `Wildcards in input files cannot be determined from output files`；且 12 个样本会争抢同一个输出文件。

**Q10（`l1_p07`，上机）** 无标准答案，看 Snakefile 与 `-n` 输出。合格 Snakefile 需含：`SAMPLES = ["a","b","c"]`（或 `glob_wildcards`）、`rule all` 的 `input: expand("...{sample}.stats", sample=SAMPLES)`、一条带 `{sample}` 的工作 rule。`-n` 应显示 3 个 job + 1 个 all。第 3 问要点：`rule all` 是 DAG 的入口，声明「最终想要哪些文件」；删掉后 Snakemake 默认以**文件中第一条 rule** 为目标，若第一条 rule 带未定值的通配符，会直接报错或只跑出一个任务——这正是 Snakemake「从输出反推输入」（pull 范式）的体现，也是 p07 第一个理论对比点。
