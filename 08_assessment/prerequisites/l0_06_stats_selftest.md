### Q8（O5，上机）从 PCA 上诊断批次结构

把下面这段代码原样跑完（`set.seed` 已固定，你的数字应当与他人一致）：

```r
set.seed(505)
n_gene <- 3000; n_samp <- 12
group <- rep(c("A", "B"), each = 6)                                     # 处理组
batch <- c("B1","B1","B1","B1","B1","B2", "B1","B2","B2","B2","B2","B2") # 建库批次
base  <- rnorm(n_gene, 8, 2)
g_eff <- c(rnorm(150, 1.0, 0.3), rep(0, n_gene - 150))
b_eff <- rnorm(n_gene, 0, 1.2)
expr  <- matrix(base, n_gene, n_samp) +
         outer(g_eff, as.integer(group == "B")) +
         outer(b_eff, as.integer(batch == "B2")) +
         matrix(rnorm(n_gene * n_samp, sd = 0.3), n_gene, n_samp)

pc <- prcomp(t(expr), scale. = FALSE)
round(100 * pc$sdev^2 / sum(pc$sdev^2), 1)[1:3]      # 各主成分解释的方差百分比
data.frame(sample = paste0("S", 1:12), group, batch,
           PC1 = round(pc$x[, 1], 1), PC2 = round(pc$x[, 2], 1))
table(group, batch)
cor(pc$x[, 1], as.integer(batch == "B2"))            # PC1 与批次的相关
cor(pc$x[, 1], as.integer(group == "B"))             # PC1 与处理的相关

png("q8_pca.png", width = 900, height = 800, res = 150)   # 图内文字一律英文
plot(pc$x[, 1], pc$x[, 2], pch = ifelse(group == "A", 16, 17), cex = 2,
     col = ifelse(batch == "B1", "#3B75AF", "#C44E52"),
     xlab = "PC1", ylab = "PC2", main = "PCA: color = batch, shape = group")
legend("topright", c("Batch 1", "Batch 2", "Group A", "Group B"), bty = "n",
       col = c("#3B75AF", "#C44E52", "black", "black"), pch = c(15, 15, 16, 17))
dev.off()
```

### Q10（O3 + O4，上机）2 万个"无差异"基因的多重检验

```r
set.seed(42)
n_gene <- 20000; n_each <- 3
ctrl <- matrix(rnorm(n_gene * n_each), nrow = n_gene)   # 两组来自完全相同的分布，
trt  <- matrix(rnorm(n_gene * n_each), nrow = n_gene)   # 真差异为零

pv <- vapply(seq_len(n_gene),
             function(i) t.test(ctrl[i, ], trt[i, ], var.equal = TRUE)$p.value, numeric(1))

sum(pv < 0.05)                          # 原始 p 值下的"显著"基因数
sum(p.adjust(pv, "BH")         < 0.05)  # BH 校正后

min(pv)                                 # 最小的 p 值

png("q10_pvalues.png", width = 900, height = 700, res = 150)
hist(pv, breaks = 50, col = "#8FB4D9", border = "white",

abline(v = 0.05, col = "red", lwd = 2, lty = 2); dev.off()
```

### 答案 Q1（O1）

| # | 检验 | 理由 |
|---|---|---|
| a | **两样本 t 检验**（R 默认 Welch） | 连续 + 2 组 + 独立 + 近似对称；n = 12 有中心极限定理兜底 |
| b | **配对 t 检验**（`paired = TRUE`） | 同一批个体的前后测量 → **配对**。按独立处理会把个体基线差异当成噪声，材料演示 1a 里这一步差了四个数量级 |
| c | **单因素 ANOVA + TukeyHSD** | 连续 + 3 组 + 近似正态；"哪两组之间"需要事后两两比较且**必须校正**（TukeyHSD 已内含校正）。做 3 次独立 t 检验而不校正是常见错误 |
| d | **卡方检验**（任一期望频数 < 5 时改 Fisher 精确检验） | 因变量是**类别/频数**（发病 / 不发病），不是连续量 |

**扣分点**（自查用）：把 b 当独立两样本；c 用三次两两 t 检验且不校正；d 用 t 检验比较"发病率"。

### 答案 Q2（O1）

1. **3 vs 3 的 Wilcoxon 秩和检验最小可能 p 值是 0.1**（`wilcox.test(1:3, 4:6)$p.value` → `0.1`）——两组完全分离时也只有 0.1。所以 `p = 0.1` 是这个设计**能给出的最强证据**，它不说明"两组没差异"，只说明**这个检验在这个样本量下永远不可能显著**。把"没检出"说成"没差异"是把**证据不足**当成**证据支持无差异**。
2. 例："在 n = 3 的设计下，Wilcoxon 秩和检验能达到的最小 p 值为 0.1，因此本检验不足以判断两组多样性是否存在差异。"（可另附效应大小与两组 Shannon 指数的实际数值。）
3. 增加生物学重复（至少 5–6 个/组）；或换用有更细分辨率的方法（如置换检验、基于距离的多元方法——后者属硕士 m06「统计插件」的内容）；并在设计阶段就用 `power` 估算而不是事后补救。

### 答案 Q3（O2）

1. 泊松下 **方差 = 均值**。逐个看 `方差/均值`：geneA 9.0/8.0 ≈ **1.1**（接近泊松）；geneB 552.3/119.7 ≈ **4.6**；geneC 1 232 100/2180 ≈ **565**；geneD 1.0/5.0 = **0.2**。**geneB 和 geneC 明显过离散**，geneC 极端。（geneD 比值 < 1 是 n = 3 的抽样噪声，不必解读为"欠离散"。）
2. `Var = μ + α·μ²` → `α = (Var − μ) / μ² = (1232100 − 2180) / 2180² ≈ **0.26**`。（生物学重复良好的实验通常 α ≈ 0.01–0.1；0.26 提示这组重复间变异很大。）
3. 要点：计数数据**非负、离散、右偏**，且**方差随均值增长**——t 检验假定的"方差与均值无关的正态分布"两条都不成立；泊松虽然是计数的自然模型，但只含**技术抽样**噪声，装不下生物学个体间的变异（过离散）。负二项多出的 `α·μ²` 项正是为这部分变异准备的，所以 DESeq2 / edgeR 用它。

### 答案 Q4（O3）

| # | 对/错 | 说明与改写 |
|---|---|---|
| 1 | **错** | 把 p 值当成"结论为真的概率"。改写："在无差异假设下，观测到这么极端数据的概率是 1%。" |
| 2 | **错** | p 值同时受**效应大小**与**样本量**驱动，不能当效应大小读。改写："两者的证据强度不同；差异大小要看 log2FC / 组间差与其置信区间。" |

### 答案 Q5（O4）

1. **约 20000 × 0.05 = 1000 个**。（材料演示 3 的实测值是 985。）
2. **不能直接这么说，但方向是对的**。正确推理：在"全无差异"的极端情形下期望约 1000 个假阳性；你观测到 1150 个，说明**超出零假设期望的部分很小**（约 150 个），因此这份列表里真信号的比例很低。严谨的量化方式是做 BH 校正看有多少通过 FDR 阈值，而不是"1150 − 1000"这样直接相减。

### 答案 Q6（O5）

1. **批次与处理完全混杂（confounding）**：批次 1 = 全部对照，批次 2 = 全部处理，两个变量携带完全相同的信息。
2. PCA 上按批次着色、按处理用形状，会看到**颜色和形状沿同一个方向、同样地分开**（材料演示 5 右图）。你无法判断这条分离轴是生物学的还是技术的。
3. **不行。** ComBat 的输入需要"批次内部有组间对比"才能把批次效应与处理效应分开；在完全混杂下，它去掉批次的同时会把处理效应一并去掉（或把两者一起留下）。**这不是软件能力问题，是信息在数据里根本不存在**。可行的只有重做实验，或在局限性里明确写出"批次与处理不可分离"。
4. 合格方案（**区组化**）：

   | | 批次 1 | 批次 2 |
   |---|---|---|
   | 对照组 | 2 | 2 |
   | 处理组 | 2 | 2 |

   每个批次内部都有两组的对比，因此批次可以作为**协变量**进入模型（`design = ~ batch + condition`），处理效应仍可估计。再加一条：样本上机顺序**随机化**，不要按组排。
5. 例（任选 3 个并说明后果）：建库日期 / 试剂批号（无法作为协变量校正）；操作人；RNA 提取批次与 RIN 值（低质量样本的系统性偏移会被误读为生物学效应）；测序 lane / 测序中心；样本采集时间与保存时长；细胞传代数。**共同后果**：没记录的变量事后补不上，只能作为"未知混杂"写进局限性。
