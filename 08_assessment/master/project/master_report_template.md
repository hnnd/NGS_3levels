# 硕士项目报告模板（期中 / 期末通用）

> **本文件是模板，不单独计分。** 评分见 `master_midterm_project.md`（期中 22%）与
> `master_final_project.md`（期末 33%）。
> 用法：把下面 `【】` 里的提示替换成你自己的内容，删掉所有提示文字与本段说明。
> **图表标题、坐标轴、图例一律用英文**（课程规则：集群 R 环境的中文字体会渲染成方块）；
> 中文解释写在正文里。

### 第 1 段 · 数据获取与实验设计

- **科学问题**：【这份数据要回答什么。一句话，不要写成综述】
- **材料与分组**：【物种/材料、样本数、分组、每组重复数】
- **建库与测序**：【建库方式（如 polyA 富集 / rRNA 去除 / 是否链特异性；16S 的引物区段）、平台、读长、数据量】
- **数据来源**：【课程路径，或公开数据的登录号与下载命令】
- **设计的局限（先写在这里，后面统计判断要回来引用）**：【重复数够不够、分组是否平衡、批次与处理有没有混杂】

> 期末项目的这一段要与 `proposal.pdf` 第 2 节对得上；不一致处须说明为什么改了。

### 第 2 段 · 质控与预处理

|---|---|---|---|---|---|
| 【S01】 | | | | | 保留 / **剔除（写明理由）** |

- **过滤参数与理由**：【参数值 + 为什么是这个值，不是"用了默认参数"】
- **异常样本处置**：【剔除必须**具名**并说明理由。静默丢样本是本课程红线】

### 第 3 段 · 主分析

- **流程与工具版本**：【每一步的工具与版本；版本号从 `env_snapshot.yml` 抄，不要凭记忆写】
- **关键参数表**：

| 步骤 | 参数 | 取值 | 选择依据 |
|---|---|---|---|
| 【比对/定量/…】 | 【】 | 【】 | 【为什么是这个值；换一个值会怎样】 |

- **诊断步骤（先看诊断，再看结果）**：【本条线的第一诊断依据——m03 的比对率与 callable region、m04 的 PCA 与 `plotDispEsts`、m05 的 FRiP 与 TSS enrichment、m06 的 track 表、m07 的 CheckM2】
- **图**：`figs/fig2_*.png`、`fig3_*.png`

### 第 4 段 · 结果解读

- **主要结果**：【数字 + 它说明什么生物学问题。不要只贴表】
- **图**：`figs/fig4_*.png`、`fig5_*.png`【每张图要能对应正文的一句话；对不上的图删掉】
- **自查："结果不对时长什么样"**：【对照所选专题讲义 ⑥ 的反例表，说明你排除了哪几种异常形态、依据是什么】

### 第 5 段 · 方法选择与结果可信度说明（≤ 2 页）

> 这一节按四问作答，**评分不看结论对不对，看推理链是否闭合**。
> 期中占 25 分、期末占 20 分（见对应任务书 ④）。

1. **为什么用这个检验 / 模型 / 工具？**【结合你的数据特点，不是"领域内都这么做"】
2. **为什么用这个阈值？**【至少两个关键阈值 + **换一个值的实测数字**】
3. **假阳性风险在哪？**【本条线特有的假阳性来源；设计上的混杂；这个设计的统计天花板】
4. **什么证据能推翻你的结论？**【下一步的验证实验；预期哪个结果最可能不重复，为什么】

## ③ 完成步骤

1. 复制本文件为 `report.md`（或直接在 Word / LaTeX 里照此结构建文档）。
2. 删掉本文件开头的说明段与所有 `【】` 提示文字。
3. 按五段结构填写；**先填第 1 段和第 5 段**——它们决定其余三段该写什么。
4. 图先出、再写图注、最后写正文——顺序反过来容易出现"有图但没论点"。
5. 导出 PDF，检查：图内无中文、页数在任务书规定范围内、正文每个数字都能在 `results/` 里找到出处。

## ⑥ 常见失分点

模板使用环节特有的问题（内容层面的失分点见各任务书 ⑥）：

| # | 失分点 | 长什么样 | 怎么自查 |
|---|---|---|---|
| 1 | **提示文字没删干净** | 报告里还留着 `【】` 或本文件开头的说明段 | 提交前全文检索 `【` 与"模板" |
| 2 | **照抄模板的结构却不填实质** | 每段只有一两句话，关键参数表是空的 | 第 3 段的参数表若少于 3 行，多半没写够 |
| 3 | **把命令行贴进正文** | 正文被命令撑到 30 页 | 命令进 `scripts/` 或附录 A，正文只留判断与结论 |
| 4 | **图注只写"XX 图"** | 读者看不出这张图要说明什么 | 图注第一句写结论，第二句写怎么读 |
| 5 | **版本号靠回忆填** | 正文写的版本与 `env_snapshot.yml` 对不上 | 版本号一律从环境快照里抄 |
| 6 | **第 5 段写成套话** | "结果可靠""需要进一步验证" | 四问每问都要有**具体数字或具体实验**，否则按未作答计 |
